### 01. Full-Stack E-Commerce Marketplace

**Status:** Planned / in development as the learning roadmap progresses

My main full-stack project will be a multi-vendor e-commerce marketplace inspired by platforms such as Amazon, Takealot, and Temu.

The goal is to build a functioning online marketplace where customers can discover products, manage their shopping carts, place orders, and track purchases, while sellers can manage their own product listings.

The project will begin with a smaller working version and grow in stages as I develop the necessary skills.

**Planned features**
- Responsive homepage and product catalogue
- Product search, categories, filtering, and sorting
- Individual product pages, images, descriptions, and pricing
- Customer registration, login, and account management
- Shopping cart and checkout workflow
- Customer order history and order status tracking
- Seller dashboard for product and inventory management
- Administrative dashboard for managing users, products, and orders
- Product reviews and ratings
- Secure payment-provider integration
- Stock and inventory tracking
- Transactional email notifications
- Search engine-friendly product pages
- Progressive Web App installation and mobile-friendly experience

**Planned technology stack**

| Area | Technologies |
|---|---|
| Structure | HTML5 |
| Styling | CSS3, responsive design |
| Frontend | JavaScript, React |
| Backend | Node.js, Express.js |
| Database | PostgreSQL, SQL |
| API | REST, JSON |
| Authentication | Secure password hashing, sessions or token-based authentication |
| Payments | Payment gateway integration using a provider's official API |
| Images and files | Object storage or an image-hosting service |
| PWA | Web app manifest, service workers, installability, caching |
| Testing | Unit tests, integration tests, end-to-end tests |
| Version control | Git, GitHub |
| Deployment | A frontend host, backend host, and managed database |
| Security | Input validation, access control, secure configuration, rate limiting |

**Installable mobile experience**

I want the marketplace to work like a modern web app on desktop and mobile. Using Progressive Web App technology, eligible users will be able to install it or add it to their home screen.

The app will include a web app manifest, appropriate icons, a service worker, and a mobile-friendly interface. Where supported by the browser and operating system, an installation prompt or install button will guide users through installation.

The installation experience will depend on the browser and device; websites cannot force an identical pop-up on every phone.

**Development roadmap**
1. Build the responsive frontend and product catalogue.
2. Add the backend and database.
3. Implement accounts, authentication, and user roles.
4. Build shopping cart, checkout, orders, and inventory.
5. Add seller and administrator dashboards.
6. Integrate a payment provider in a test environment.
7. Add PWA features and mobile installation support.
8. Test, document, secure, and deploy the application.

The initial version will use sample products and test transactions. Real payments, seller onboarding, and production deployment will only be added once the relevant security and operational requirements are addressed.
